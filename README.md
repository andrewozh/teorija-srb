# 🇷🇸  Teorija

A PWA for preparing for the Serbian driving license theory exam.

**[→ Open the app](https://andrewozh.github.io/driving-theory-srb/)**

## What's inside

- 2288 questions from the official MUP Srbije database
- 7 sections, vehicle categories A–M
- Serbian + Russian language
- SRS-based learning, practice mode, mock exams
- Dark and light themes
- Progress stored locally

## Stack

Svelte 5 · SvelteKit · Static adapter · GitHub Pages

## Development

```bash
cd app && make dev      # dev server
cd app && make deploy   # build + deploy to gh-pages
```
